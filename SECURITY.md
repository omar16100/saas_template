# Security Policy

## Supported versions

Latest `main` only. This is a template — fork it and own your own fork.

## Reporting a vulnerability

Email: omarshabab55@gmail.com

Please include:
- A description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fix

Do **not** open a public GitHub issue for security reports.

You'll get an acknowledgement within 72 hours. Disclosure timeline is negotiated case-by-case.

## Out of scope

- Issues in third-party services (Stripe, Resend, Cloudflare) — report to them directly.
- Theoretical weaknesses with no practical exploit path in a default install of this template.
